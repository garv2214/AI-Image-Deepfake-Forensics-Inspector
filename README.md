# AI-Image & Deepfake Forensics Inspector

A full-stack, **4-layer forensic verification web application** that determines whether a photograph is camera-authentic, manually altered (spliced/Photoshopped), or synthetically generated by AI—and **visually proves why** using side-by-side interactive proof maps.

---

## Core 4-Layer Forensic Pipeline

| Layer | Module | Signal Analyzed | Visual Proof Output |
| --- | --- | --- | --- |
| **Layer 1** | `metadata.py` | EXIF camera hardware signatures, Photoshop/GIMP footprints, Stable Diffusion/ComfyUI PNG chunks, XMP IPTC `trainedAlgorithmicMedia`, and C2PA JUMBF markers | Structured Responsive Provenance Audit Table |
| **Layer 2A** | `ela.py` | Error Level Analysis (in-memory JPEG Q90 re-compression, adaptive pixel diff, edge-normalized $16 \times 16$ spatial block z-scores) | Inferno ELA Heatmap + Amplified RGB Residual + Hotspot Bounding Boxes |
| **Layer 2B** | `fft.py` | Hann-windowed 2D Fast Fourier Transform, off-axis periodic upsampling peak detector, azimuthal radial power vs. natural $1/f^\alpha$ decay | 2D Log-Magnitude Spectrum + Interactive Recharts Radial Frequency Chart |
| **Layer 3** | `deep_model.py` | Local HuggingFace Swin Transformer (`Organika/sdxl-detector`) on Apple MPS / CUDA / CPU + real spatial **Grad-CAM** backward hooks | Jet-blended Grad-CAM Spatial Attribution Overlay |
| **Layer 4** | `fusion.py` | Calibrated weighted fusion separating **Full-Frame Synthetic Probability** from **Localized Tampering Score** | Dual `<progress>` Rings, Nuanced Verdict Badge, One-Click PDF & JSON Dossier |

## Quick Start (100% Local & Offline-Ready)

### 1. Start Both Backend & Frontend
```bash
./start_dev.sh
```
- **Web Dashboard:** http://localhost:3000
- **FastAPI Swagger Docs:** http://127.0.0.1:8000/docs

### 2. Run Automated Tests
```bash
make test
```

### 3. Run Quantitative Evaluation (CIFAKE / 140k Faces / CASIA)
```bash
./backend/.venv/bin/python backend/scripts/evaluate_benchmark.py \
  --dataset-dir /path/to/dataset_with_real_and_fake_folders \
  --max-per-class 500
```

### 4. Pre-Cache Model for Offline Presentations
The pretrained `Organika/sdxl-detector` weights are cached locally in `backend/model_cache/`. To refresh or swap models (e.g., `FORENSICS_HF_MODEL_ID=umm-maybe/AI-image-detector`):
```bash
make download-model
```

## Privacy & Limitations

- **Ephemeral RAM-Only Processing:** Uploaded files are never written to disk; all decoding, re-compression, FFT, and neural inference run strictly in memory.
- **Decision Support, Not Courtroom Proof:** Heavy social-media re-compression (WhatsApp/Instagram) attenuates ELA and high-frequency cues, and unseen generative models require periodic fine-tuning. See [docs/VIVA_DEFENSE_GUIDE.md](docs/VIVA_DEFENSE_GUIDE.md) for full engineering details.
